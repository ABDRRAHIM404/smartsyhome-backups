# SmartsyHome Backups

Public documentation for the owner's encrypted backup utility. This repository
contains only static website files. The private SmartsyHome application,
backup automation, archives and credentials are not part of this repository.

- Homepage: https://abdrrahim404.github.io/smartsyhome-backups/
- Privacy policy: https://abdrrahim404.github.io/smartsyhome-backups/privacy/
- Search Console instructions: https://abdrrahim404.github.io/smartsyhome-backups/verification/

GitHub Pages publishes `main` from the repository root. `.nojekyll` keeps the
site plain HTML/CSS. No package installation, paid hosting or custom domain is
required. Preview locally with `python3 -m http.server 8000`.

## Google Search Console

Follow the site's verification guide linked above. Verification requires the
owner's Google login and Google's exact verification file or HTML meta tag.
Keep that artifact deployed after verification. No verification artifact is
invented or preinstalled, and this repository does not publish the OAuth app.

## Updating the policy

Keep the policy consistent with actual permissions, providers, activation and
retention. The integration is currently in setup; scheduling and Gmail alerts
are not active. Update that status after an authorized configuration change.
Never put tokens, credentials, recovery keys, private code or backups here.
