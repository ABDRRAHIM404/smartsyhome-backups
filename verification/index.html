For the site owner

Verify this website.

Search Console verification proves website ownership. It does not publish or approve a Google OAuth application.

Google Search Console

  1. Sign in to Google Search Console with the owner’s Google account.
  2. Add a URL-prefix property for https://abdrrahim404.github.io/smartsyhome-backups/. Include HTTPS, the repository path and the trailing slash.
  3. Choose HTML file upload. Download Google’s verification file.
  4. Add that exact file, unchanged, to the public repository’s root on main. Commit and push. Publish only Google’s website-verification file, never an OAuth credentials file.
  5. Wait for Pages deployment. Open the exact verification URL Google provides and confirm the file loads, then click Verify.
  6. Keep the file deployed; Google can check it again later.

If HTML-tag verification is offered instead, add Google’s exact google-site-verification meta tag inside the homepage’s <head>, publish, then verify. No verification token has been generated or installed yet.

Google’s official verification instructions

Keep the boundaries clear

Verify only the Pages property you control. GitHub owns the github.io DNS zone, so a DNS-based Domain property is not the appropriate starting point here. Website ownership verification is separate from Google OAuth consent-screen configuration; this deployment changes neither OAuth permissions nor app publication status.
