A small, deliberate system

Protection with a clear purpose.

No customer accounts or public file uploads. The utility serves the SmartsyHome owner’s backup and recovery needs.

ENCRYPTION

Private before it leaves.

The prepared runner encrypts archives with AES-256 authenticated encryption before uploading them. Unencrypted content is not published on this website.

GOOGLE DRIVE

Access for backups only.

With the owner’s authorization, the utility stores and manages its backup files in a designated private Drive folder. Google access is used for backup storage, recovery and retention.

RECOVERY

A copy you can check.

The prepared process downloads an uploaded archive, checks integrity, decrypts it and verifies recovered content and media before recording success.

Clear boundaries

Documentation stays public.
Backup data stays private.

Google authorization and unattended delivery are still being configured. This website does not grant Drive access or change the Google OAuth app’s publication status.
